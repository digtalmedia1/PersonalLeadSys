## Deployment

1. Install dependencies with `npm install`.
2. Build the project using `npm run build`.
3. Upload the contents of the `dist` folder to your Hostinger site's `public_html` directory.
4. Include the provided `.htaccess` file so that all unknown paths are rewritten to `index.html`, ensuring SPA routes work with deep links.
